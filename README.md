# Route58 Manager para Android

App móvil de **Route58**, la plataforma de localización y telemetría de Fusión58.

La app es un contenedor nativo (WebView) que carga la web de Route58 (`https://route.fusion58.com`) y le suma capacidades del teléfono: notificaciones push, autenticación biométrica y descarga de archivos.

- Producción: https://route.fusion58.com
- Repo: https://github.com/fusion58/route58-manager-android
